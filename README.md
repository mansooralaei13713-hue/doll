# عروسک‌ساز | Doll Studio

یک پروژه‌ی شروع Flutter برای طراحی عروسک‌های کارتونی با اشکال برداری، تغییر رنگ پوست/مو/لباس/پس‌زمینه و گرفتن خروجی PNG.

## قابلیت‌ها
- تغییر رنگ پوست، مو، لباس و پس‌زمینه
- انتخاب مدل مو، لباس و چشم
- روشن/خاموش کردن پاپیون و گونه‌ها
- رندر عروسک با `CustomPainter` (بدون نیاز به فایل تصویر خارجی)
- خروجی PNG با وضوح بالاتر و باز کردن پنجره‌ی اشتراک‌گذاری اندروید

## اجرای محلی
نیازمند Flutter و Android SDK نصب‌شده است.

```bash
flutter create --platforms android .
flutter pub get
flutter run
```

اگر فرمان `flutter create` درباره‌ی فایل‌های موجود پرسید، از گزینه‌ی حفظ فایل‌های فعلی استفاده کنید. فایل‌های `lib/main.dart` و `pubspec.yaml` را جایگزین نکنید.

## ساخت APK
```bash
flutter build apk
```
فایل خروجی:
`build/app/outputs/flutter-apk/app-release.apk`

برای APKهای کوچک‌تر و جداگانه برای معماری‌های مختلف:
```bash
flutter build apk --split-per-abi
```

## بارگذاری روی GitHub
1. یک مخزن جدید در GitHub بسازید.
2. کل محتوای این پوشه را بارگذاری کنید.
3. فایل‌های سورس و workflow همراه پروژه هستند؛ برای ساخت محلی، مراحل بالا را اجرا کنید.

## ساخت خودکار APK در GitHub Actions
پس از push کردن پروژه به شاخه‌ی `main`، از تب **Actions** اجرای workflow را بررسی کنید. خروجی APK به‌عنوان artifact قابل دریافت خواهد بود.

این نسخه یک نمونه‌ی پایه است؛ طراحی عروسک با اشکال برداری انجام می‌شود و فعلاً قابلیت وارد کردن قطعات تصویری دلخواه، ذخیره‌ی چند پروژه یا لایه‌بندی آزاد ندارد.
